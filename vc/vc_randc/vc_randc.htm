VC_RANDC

 

Overview

vc_randc returns the random-cyclic value within the set of predefined range.

 

 Syntax

vc_randc #(min,max) <inst_name> ();

 

Parameters

min

Low limit of the predefined range

max

Upper limit of the predefined range

Access Functions

Name

Arguments

Description

get

Dummy (0)

Returns the random-cyclic value within the specified range

 

 

 

 

 

 

 

 

 

Verilog example

 

module test;

integer i;

vc_randc #(3,8) randc();

 

initial begin

  for (i=0; i< 20; i=i+1)

    #10 $display("i = %0d; randc = %0d", i, randc.get(0));

  #10 $finish;

end

 

endmodule
