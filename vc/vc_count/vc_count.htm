VC_COUNT

 

Overview

VC_COUNT represents the counter module. This is very useful infrastructure component for building verification environments. Access task allow counter reset, as well as switching the counting on and off.

 

Syntax

vc_count InstName (clk, rst_n);

 

Interface

clk

Clock

rst_n

Active-low reset

 

 

Access Tasks

Name

Arguments

Description

reset

No

Resets counter, setting counter value to 0

on

No

Enables the counter incrementing function

 

Example:   

count.on;

off

No

Disables the counter incrementing function

 

Example:   

count.off;

Access Registers

val

The counter value

 

 

 

Example

 

module test;

 

reg clk, rst_n;

initial begin

  clk = 1;

  rst_n = 0;

end

always #5 clk <= ~clk;

vc_count count (clk, rst_n);

initial begin

  #20 rst_n = 1;

  #30 count.on;

  #40 $display("[%0t] count = %0d", $time, count.val);

  #30 count.off;

  #50 count.on;

  #20 $display("[%0t] count = %0d", $time, count.val);

  #50 count.reset;

  $display("[%0t] count = %0d", $time, count.val);

  #50 $finish;

end

endmodule
